# Pre-packaged reference data
This data is included in the reproducibility repository to simplify re-analysis workflows.
## Data sources
`borzoi-human-splits` are from https://github.com/calico/borzoi/tree/main/data

`pwms` are generated using https://github.com/calico/scBasset/blob/main/examples/ISM/make_pwm.R, with additional manually-created files for CpG-only motifs (CG1,32,3,5,10) and random motifs (UNIFORMRANDOM5,10,15,20)

`imprinted_genes.csv` is from https://www.geneimprint.com/site/genes-by-species

`transcription_factor_metadata.csv` is synthesized from https://pubmed.ncbi.nlm.nih.gov/28473536/ with additional curated motifs as described
